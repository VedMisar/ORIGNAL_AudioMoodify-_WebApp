# AudioMoodify - Web Music Streaming App 🎵 Developed by Vidyam Technologies PVT LTD

AudioMoodify is a full-stack web music streaming application inspired by Spotify. It offers a green futuristic UI and allows users to sign up, log in, browse songs, create playlists, and play music seamlessly with a dynamic audio player. Integrated with the YouTube API, it fetches songs for streaming directly within the app.

## Features

- User authentication (Sign up / Log in)
- Browse and search songs by artists or playlists
- Create, edit, and delete playlists
- Dynamic audio player with play, pause, skip, and volume controls
- Voice search for songs
- Futuristic green-themed UI with smooth animations
- Fully responsive design

## Tech Stack

- **Frontend & Backend**: Next.js (React + Node.js)
- **Database**: MongoDB
- **API Integration**: YouTube API for fetching songs
- **Styling**: Tailwind CSS

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/VedMisar/ORIGNAL_AudioMoodify-_WebApp.git
   cd AudioMoodify_Final_Cleaned_audiomoodify30

2.Install dependencies: npm install

3.Create a .env.local file in the root directory and add your MongoDB URI and YouTube API key:

MONGODB_URI=your_mongodb_connection_string
YOUTUBE_API_KEY=your_youtube_api_key

4.Run the app locally:

npm run dev

5.Open http://localhost:3000
 in your browser.
